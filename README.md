# TaskManager

Нативный (WPF, .NET 10) оффлайн-трекер задач в духе Linear для соло-разработчика.
В комплекте MCP-сервер: Claude может читать, создавать и обновлять задачи.

## Возможности
- Проекты с ключами (`TM-42`), задачи со статусами (Бэклог → К выполнению → В работе → Готово/Отменено) и приоритетами (Срочно/Высокий/Средний/Низкий)
- Список с группировкой по статусу и канбан с drag&drop
- Метки, подзадачи, перенос задач между проектами
- Описание в Markdown: заголовки, списки, кликабельные чек-листы, код, таблицы, цитаты, ссылки
- Вставка скриншотов через `Ctrl+V` и перетаскиванием файлов; URL поверх выделенного текста превращается в ссылку; `TM-1` в тексте — ссылка на задачу
- Полнотекстовый поиск (SQLite FTS5) и командная палитра `Ctrl+K`
- Копирование ID задачи и имени git-ветки (`tm-42-fix-login-crash`)
- Бэкап в zip и восстановление из него

## База данных
Раздел «База данных» в сайдбаре — заметки в обычных папках на диске:
- **Источник** — любая папка (`＋` → выбрать папку). Источников может быть несколько; «Убрать из списка» не трогает файлы.
- **Записи** — `.md` файлы, **папки** — настоящие папки (скрытые вроде `.git`, `.obsidian` пропускаются).
  Название записи = имя файла; переименование, перемещение (перетаскиванием в дереве) и удаление (в корзину Windows) работают с файлами напрямую.
  Изменения из других программ подхватываются автоматически.
- **Теги** — пишутся текстом в записи: `#тег`, `#проект/бэкенд`. Видны в дереве, в шапке записи и подсвечены в тексте;
  клик по тегу фильтрует записи. Цвет при первом появлении выбирается случайно из палитры и хранится в БД; правый клик по тегу — сменить.
- **Связь с задачами**: в карточке задачи блок «Записи из базы» (`＋ Привязать`), а набранное в описании `[[` вставляет ссылку на запись
  (и привязывает её). В записи видны связанные задачи. Ссылки и привязки обновляются при переименовании/перемещении.
  `TM-12` внутри записи — ссылка на задачу.
- **Obsidian Sync**: если источник лежит внутри хранилища Obsidian (есть `.obsidian`), синхронизация включается сама
  (переключатель — правый клик по источнику, значок ⟳). После изменений из TaskManager или через MCP, через ~4 секунды:
  если хранилище открыто в запущенном Obsidian — ничего не нужно, Obsidian сам заметит файлы и Sync их загрузит;
  иначе хранилище открывается через `obsidian://open?vault=…`, и Obsidian Sync синхронизирует его при запуске.
  Состояние хранилищ берётся из `%APPDATA%\obsidian\obsidian.json`. Есть и ручной пункт «Синхронизировать через Obsidian сейчас».

## Горячие клавиши
| Клавиша | Действие |
|---|---|
| `C` / `Ctrl+N` | новая задача |
| `Ctrl+K` | поиск и команды |
| `/` / `Ctrl+F` | фильтр |
| `J` `K` `↑` `↓` | навигация |
| `E` / `Enter` | редактировать описание, `T` — заголовок |
| `S` `P` `L` `M` | статус, приоритет, метки, проект |
| `1`–`4`, `0` | приоритет / без приоритета |
| `Delete` | удалить задачу |
| `Ctrl+B` | список ↔ канбан |
| `Esc` | закрыть / назад |

В редакторе описания: `Ctrl+B`/`Ctrl+I` — жирный/курсив, `Ctrl+K` — ссылка, `Tab` — вложить пункт списка, `Enter` продолжает список.

## Данные
`%LOCALAPPDATA%\TaskManager\` — `data.db` (SQLite) и папка `attachments\`.
Файл `portable` рядом с exe переключает хранение в папку `data\` рядом с ним; переменная `TASKMANAGER_DATA` задаёт любой путь.

## Claude (MCP)
`TaskManager.Mcp.exe` — stdio MCP-сервер, работающий с той же базой, что и приложение.
Открытое приложение подхватывает изменения от Claude в течение секунды.

Инструменты: `list_projects`, `list_labels`, `list_issues` (фильтры и полнотекстовый поиск), `get_issue`
(описание, подзадачи и вложенные картинки как изображения), `create_issue` (в т.ч. подзадачи),
`update_issue` (статус, приоритет, метки, `append_description` для заметок), `delete_issue`,
`attach_image`, `create_project`, `create_label`.

База данных: `kb_list_sources`, `kb_add_source`, `kb_list` (папки, поиск, фильтр по тегу), `kb_read`, `kb_write`
(создать/перезаписать/дописать), `kb_create_folder`, `kb_rename`, `kb_move`, `kb_list_tags`, `kb_set_tag_color`,
`link_entry`. Удаления записей через MCP нет намеренно — только из приложения, в корзину.

**Claude Code:**
```bash
claude mcp add taskmanager --scope user -- "C:\Users\preda\Documents\Projects\TaskManager\publish\TaskManager.Mcp.exe"
```

**Claude Desktop** — `%APPDATA%\Claude\claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "taskmanager": {
      "command": "C:\\Users\\preda\\Documents\\Projects\\TaskManager\\publish\\TaskManager.Mcp.exe"
    }
  }
}
```
Другая папка с данными: добавьте аргументы `["--data", "D:\\path"]`.

Примеры запросов: «что у меня в работе?», «создай баг в TM: падает экспорт, приоритет high»,
«возьми TM-12, сделай и отметь готовой с кратким описанием изменений».

## Сборка
```bash
dotnet test
dotnet run --project src/TaskManager
dotnet publish src/TaskManager -c Release -o publish
dotnet publish src/TaskManager.Mcp -c Release -o publish
```
`publish\TaskManager.exe` и `publish\TaskManager.Mcp.exe` — самодостаточные файлы, .NET ставить не нужно.

Иконка генерируется из геометрии `assets/logo.svg`: `dotnet run assets/make-icon.cs -- src/TaskManager/Assets`.

Структура: `src/TaskManager.Core` — модели и SQLite-репозитории, `src/TaskManager` — WPF-приложение,
`src/TaskManager.Mcp` — MCP-сервер, `tests` — xUnit.
